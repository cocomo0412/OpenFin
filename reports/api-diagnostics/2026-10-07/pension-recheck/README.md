# 연금저축 API 5건 재시험

확인 시각: **2026-10-07 17:15:43~17:15:44 한국시간**. 금융감독원 직접 API `annuitySavingProductsSearch.json`에 기존 인증 환경으로 요청했다. 이번 시험의 요청 제한은 30초이며 서비스 수집기 코드는 변경하지 않았다.

## 결과

5개 금융권 모두 HTTP 200, 제공기관 코드 000으로 연결·인증에 성공했다. 응답은 0.142~0.256초 이내로 시간 초과가 없었다. 그러나 **반영 가능한 정상 연금저축 자료는 확인되지 않았다.**

| --- | ---: | ---: | --- |
| 020000 | 0 | 5 | 전체 수보다 실제 행이 많음. 연금 필드 pnsn_kind 없음 |
| 030200 | 0 | 5 | 전체 수보다 실제 행이 많음. 연금 필드 pnsn_kind 없음 |

| 060000 | 297 | 0 | 총건수가 있는데 첫 페이지가 비어 있음 |

행이 반환된 네 금융권의 baseList에는 `loan_type`, `loan_limit`, `rpay_type`, `lend_rate_type` 등이, optionList에는 `lend_rate_min`, `lend_rate_max`, `lend_rate_avg` 등 대출 관련 필드가 있었다. 기존 연금저축 수집 계약과 맞지 않으므로 정상 자료로 취급하지 않는다. 제공기관 내부 라우팅·데이터 생성 원인은 이번 시험만으로 확정할 수 없다.

## 범위와 증적

- `run.mjs`: 비공개 환경변수 인증, 공식 API만 사용, 요청당 30초, 요청 오류만 최대 2회 허용. 실제 실행은 모든 그룹 1회씩 총 5요청이다.
- 모든 그룹에서 첫 페이지 검증에 실패하여 후속 페이지를 요청하지 않았다. 전체 연금저축 목록을 수집했다고 표현하지 않는다.
- `result.json`: 요청 시각·상태·시간·총수·수신행·필드명·응답 해시를 기록. 인증키·인증 URL·원문 상품 응답은 저장하지 않는다.
- 공식 개발 안내 페이지 열람은 웹 도구에서 접근 불가였다. 이번 기록은 실제 API 응답 및 현재 수집 계약 검증 결과이며 최신 개발 문서를 재확인했다고 주장하지 않는다.
- 비공개 추가수집 파일, 공개 수집 현황, 공개 manifest의 해시가 모두 실행 전후 동일하다. 기존 정상 자료와 원래 날짜, 기존 공개 보류 기록을 유지했다.
- 홈페이지·MCP: 진단 기록만 추가했으므로 배포 불필요. 서비스 코드·자료 변경과 원격 반영 없음.
