# 2026-10-15 공식 API 자료 갱신

한국시간 2026년 10월 15일 사용자 요청에 따라 공식 API 수집, 실패 요청의 1회 재시도, 기존 자료 보존, 검색 자료 재생성을 수행했다. 수집일과 제공기관의 공시·관측 기준일은 별도로 유지한다. 웹 크롤링이나 PDF 추출로 실패 자료를 대체하지 않았다.

예·적금의 제공기관 공시월은 `202609`이며 수집일은 `2026-10-15`이다. 홈페이지 분야별 총계에는 분류·출처·기존 보존 자료 등이 포함되므로 위의 현재 API 상품 건수와 다를 수 있다.

검색 총계는 신규 상품·지원사업 15개 증가, ECOS와 펀드 관측 자료 59개 감소로 순감 44개다. ECOS 최근 45일 범위의 관측 행은 43→39개, 펀드 기본정보의 이번 기준일 응답은 206→151개다. 원자료 기반 식별자 변경까지 포함한 전체 검색 ID 비교에서 기존 상품·지원사업·세금 항목 삭제는 없었다. 독립 검증의 상세 결과는 [qa.md](qa.md)에 기록한다.

## 실패와 보존

- 금융감독원 직접 FinLife API의 `annuitySavingProductsSearch` 5개 업권 요청은 다시 실패했다. 4개 업권은 연금저축 응답 구조와 불일치, 1개는 페이지 수집 불완전이다. 정상 상품으로 임의 해석하지 않고 기존 자료와 날짜를 유지했다.
- 공공데이터포털 경로의 금융위원회 변액보험정보 `getFundInfo`는 최초 요청과 실패 대상 재시도에서 모두 시간 초과였다. 2026-10-07 수집본, 원자료 기준일 20260930을 유지했다.
- API 미제공·수집 대상 외 자료와 기존 웹 기반 자료는 수집일을 오늘로 바꾸지 않았다. 날짜·원문 유지 대상 9,383개를 기준 커밋과 전량 대조했다.
- 기관 직접 API와 공공데이터포털 경로는 기존 출처·수집 명세를 유지한다. 인증 정보는 비공개 실행 환경에서만 읽었다.

## 검증과 증적

- [baseline.json](baseline.json): 갱신 전 로컬·운영 커밋, 자료 버전과 수집 현황.
- [initial-pipeline.json](initial-pipeline.json), [retry-pipeline.json](retry-pipeline.json), [final-pipeline.json](final-pipeline.json): 전체 수집, 실패 대상 재시도, 최종 자료 생성·검증 단계.
- [initial-public-api.json](initial-public-api.json), [final-public-api.json](final-public-api.json), [final-finlife-status.json](final-finlife-status.json): 요청별 성공·실패와 보존 근거.
- [secret-scan.json](secret-scan.json): Git 추적 파일과 공개 산출물 등 16,344개 검사, 사용 중인 API 키 및 URL 인코딩 변형 노출 0건.
- 자료 파이프라인 검증 통과: API 통합·보존 Node 검사 13개, Python API 검사 15개, 무료 카탈로그 검사 6개, 스키마·규칙·품질 상태 정합성 검사.
- 브라우저에서 신규 농촌사랑 예금 2개 검색, 상세 원문·제공기관·2026-10-15 반영일·202609 공시월을 확인했다.
- 추가 전체 회귀검사: 147개 중 141개 통과, 6개 실패. 전체 통과로 보고하지 않는다. 기존 기대값 불일치 4개는 기준 커밋에서도 존재하며 이번에 코드·검사·workflow를 수정하지 않았다. 상세 근거는 [qa.md](qa.md)에 기록했다.
- 실행 중 빌드 충돌의 영향을 받은 2개는 순차 단독 재검사에서 모두 통과했다: [decision-recheck.log](decision-recheck.log), [deterministic-recheck.log](deterministic-recheck.log). 최종 공개 파일의 재빌드 전후 바이트 일치도 확인했다.
- 오래된 고정 건수에 의존하는 Gov24 검사는 최신 공식 응답에서 대상 9,316개를 다시 산출해 ID·원문·지원대상 설명·미확정 자격 상태를 전량 검증했다: [gov24-verification.json](gov24-verification.json). 원래 테스트를 수정하거나 실패를 숨기지 않았다.
- 최종 빌드 후 품질 정합성 검사도 통과했다. 비교·추천 허용 범위를 넓히지 않았으며 `recommendation_enabled=false`를 유지한다.

## 반영 대상

- 홈페이지: 갱신된 공식 API 원자료·출처·검색 인덱스·manifest를 반영해야 한다. 문구, 디자인, 서비스 소스는 변경하지 않았다.
- MCP: 코드·설정·의존성·무료 번들·세금 원자료가 기존 운영본과 동일하므로 재배포하지 않는다. 무료 세금 검색·조회 범위를 유지한다.
- 로컬 기록과 운영 배포 결과는 구분한다. 실제 운영 커밋·Pages 배포·공개 파일 검증은 배포 후 별도 기록한다.
- 다음 수동 갱신 목표는 2026-10-22(7일 간격)다. 자동 예약은 생성하지 않았다.
