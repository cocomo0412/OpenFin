# 2026년 10월 7일 OpenFin 자료 갱신

직전 전체 수집 기준일은 2026년 10월 1일이다. 이번 회차는 공식 API만 이용한 **부분 갱신**이며, 10월 7일 14:52 한국시간에 수집·통합 파이프라인과 필수 검사를 완료했다. 개별 자료의 수집일·제공기관 기준일은 구분해 보존했다. 홈페이지 운영 반영은 별도 배포 증적으로 관리한다.

| 구분 | 결과 |
| --- | --- |
| 공공 API 및 한국은행 API | 27개 수집본, 57,493행 성공 |
| 금융감독원 대출 API | 10개 수집본, 281행 성공 |
| 정부24 공식 API | 10,951행 성공 |
| 예금·적금 | 전체 수집 단계가 두 차례 시간 초과. 767개 항목의 10월 1일 정상 자료 유지 |
| 연금저축 | 5개 요청 보류: 응답 구조 불일치 4개, 페이지 불완전 1개 |
| 공개 목록 | 총 75,743개 중 오늘 수집 자료 반영 67,392개, 기존 유지 8,351개 |

원문 행 수와 공개 목록의 중복 제거 항목 수는 다른 단위다. 보류 6건은 연금저축 요청 5개와 예·적금 수집 단계 1개를 합친 기록 수이며, 같은 단위의 API 실패 요청 6개로 표현하지 않는다. 정규 통합 보고서의 68,159개에는 재사용한 예·적금 767개가 포함되므로 오늘 갱신 수치로 사용하지 않는다.

전체 항목은 80,944개에서 75,743개로 5,201개 줄었다. 실손보험 -5,232, 펀드 -163, ECOS -3, 은행통계 +161, 퇴직연금 +32, 지방 혜택 +4의 합계와 일치한다. 실손보험 API의 조회 기준일은 2026-09-01에서 2026-09-21로 바뀌었으며 새 응답의 전체 건수와 실제 행 수는 2,224개로 일치한다. **상품 판매 종료나 전체 시장 축소를 뜻하지 않는다.** 이전 기준 자료는 Git 및 이번 회차 전 증적으로 보존했다.

유지 항목은 이전 성공 자료 7,342개, 최근 목록에서 미확인한 과거 항목 293개, 구조·출처 정보 306개, 유지 원인 추가 분류 대상 410개다. 웹 기반 자료를 API 수집 자료로 바꾸거나 법령의 현재 적용 여부를 새로 확인했다고 표시하지 않았다.

## 실행·보완·검증 기록

1. 이전 정상 수집본 31개를 별도 작업 폴더에서 원래 바이트로 복사하고 해시를 기록했다. API 인증값은 비공개 기존 환경에서만 읽었다.
2. 첫 실행은 공공 API 26개 성공·변액보험 시간 초과 후 예·적금도 시간 초과로 중단됐다. 원본 자료 복구를 확인했다.
3. 한 차례 전체 재시도에서 공공 API 27개가 모두 성공했지만 예·적금은 다시 시간 초과가 발생했다. 성공한 수집본을 별도 보존하고 검증했다. 복구 중 Windows 파일 이동 오류가 발생했으나 복구 재시도와 원본 31개 해시 대조를 완료했다.
4. 예·적금·정부24 단계 실패 시 당일 실패 증적과 검증된 이전 정상본을 연결해 유지하는 경로를 추가했다. 날짜·출처·건수·식별자·체크섬·원바이트 해시가 맞지 않으면 차단한다. 구현 담당과 다른 담당이 검토했다.
5. 실제 두 번째 실패 기록과 사전 해시로 예·적금 보류를 확인하고 추가 대출·연금 및 정부24부터 재개했다. 공공 API 성공 27개를 다시 호출하지 않았다. 이전 실행의 근사 점검 시각은 `checked_at_basis`로 구분했다.

필수 검사: 자료 검증·규칙 검증, 통합·부분 갱신 Node 검사 13개, 공공 API Python 검사 15개, 무료 카탈로그 검사 6개, 검색·웹 보안 검사 57개 모두 통과했다. 재개 전 독립 실행한 부분 갱신·복구 검사 21개도 통과했다. 목록 간 중복 검사가 있어 숫자를 합산한 고유 검사 건수로 표현하지 않는다. 저장소·공개 산출물·보고서·로그 9,006개 파일에서 실제 사용 키의 원문·URL 인코딩 값이 발견되지 않았다.

## 운영 주기와 배포 구분

갱신 목표는 되도록 **7일 간격**, 다음 목표일은 **2026년 10월 14일**이다. 실행 시각은 미정이며 자동 예약은 생성하지 않았다. 개발·운영 매뉴얼은 같은 변경 묶음의 **1.6.0**으로 갱신했다.

- 홈페이지: 공개 수집본·검색 자료·날짜가 변경되어 배포 대상이다. 검증 결과와 별도로 운영 반영 증적을 추가한다.
- MCP: 무료 MCP 코드·설정·의존성·세금 원자료·카탈로그가 원격 main과 동일하므로 재배포하지 않는다.

상세 수치는 [회차 결과](result.json), 원본 대조는 [사전 기록](preflight.json), 품질 검토는 [독립 검토](independent-review.md), 키 값 검사 결과는 [노출 검사](secret-scan.json)에 있다. 실행별 증적은 `attempt-01/`, `attempt-02/`, `attempt-03/`에 구분했다. 최신 항목별 유지 사유는 [갱신 원장](../../refresh/README.md)을 따른다.
