## 확인 결과

- 정적 홈페이지의 태그를 제외한 문구와 순서를 기준 커밋과 비교했다. 공백·단락 경계를 정규화하면 완전히 동일하다.
- 문장별 단락 분리와 CSS 줄바꿈 규칙만 변경되며, 한글은 `keep-all`, 긴 식별자는 `overflow-wrap: anywhere`로 처리한다. 홈 전용 CSS의 `#top` 범위로 적용된다.
- 추가 요청에 따른 인접 문단 여백을 최종 CSS에서 재확인했다. 문장 그룹·온톨로지 설명·섹션 설명·MCP 카드·수집 상세의 인접 문단과 `.source-status-summary + .source-status-summary`에 `margin-top: 4px`가 적용된다. 최초 6px에서 줄인 최종값이며, 이번 추가 검토는 CSS와 적용 범위 확인만 수행하고 전체 테스트를 반복하지 않았다.
- 주담당의 DOM 검사에서 확인한 공통 `.source-status-summary`의 `12px !important` 우선순위를 반영해 재검토했다. 최종 홈 전용 인접 선택자는 `margin-top: 4px !important`이며, 공통 규칙보다 높은 우선순위로 해당 문장 사이만 덮어쓴다. 처음 검토한 일반 4px 선언만으로는 이 공통 규칙을 덮어쓰지 못하므로, 최종 통과 판정은 이 보완까지 포함한다.
- 전체 행간 추가 요청의 최종 CSS를 검토했다. 명시된 본문 선택자는 `--home-body-leading: 1.6`, 보조 정보 선택자는 `--home-detail-leading: 1.45`를 사용하며, 기존 글자 크기는 변경하지 않는다. 연결 단계 항목의 내부 간격은 4px다. 홈 범위의 높은 선택자 우선순위를 사용하고, 기존 행간 규칙에 이를 막는 `!important` 선언은 없다. 추가 정적 검토에서 수정 필요 사항은 발견하지 못했다.
- 동적 수집 현황은 기준 커밋 코드와 변경 코드를 별도 VM에서 실행해 비교했다. 로컬에 저장된 실제 JSON을 입력하고 문장별 단락 경계를 공백으로 읽어, 표시 문구·날짜·건수·요청 경로·추가 안내 위치가 일치함을 확인했다.
