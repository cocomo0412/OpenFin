## 강제 줄바꿈과 자동 줄바꿈 구분

- 상단 소개·운영목적 HTML 소스 중간의 개행은 white-space:normal이므로 화면의 강제 줄바꿈이 아니다.
- index.html의 직접 br은 최종 기준일 보조표기와 MCP 첫 안내에 있다. MCP는 ‘서버입니다.’ 문장이 끝난 뒤 다음 줄이어서 문장 중간 강제 분리 사례가 아니다. 구조를 통일한다면 두 p로 분리할 수 있다.
- app.js 자료 카드의 br은 날짜/건수, 이력/설명 구분이다. 일반 본문 문장 중간에 br을 삽입한 문제와 다르다.
- 상단 소개와 운영목적은 이미 word-break:keep-all이다. 긴 한 문장이 폭에 맞춰 여러 줄이 되는 현상은 정상이다. 한 문장을 억지로 한 줄에 고정하면 모바일에서 넘치므로 그렇게 처리하지 않는다.
- URL·manifest 버전·API 식별자는 길어서 중간 줄바꿈이 필요할 수 있다. 이를 본문 한글과 동일한 규칙으로 일괄 금지하지 않는다.

## 문단 기준

1. 문구·의미를 바꾸지 않는다.
2. 여러 문장인 소개·설명은 완결된 문장 다음에 다음 문단을 시작한다.
3. 문장 안의 자동 줄바꿈은 단어 경계를 우선한다.
4. 긴 URL·식별자만 별도 긴 문자열 처리로 넘침을 막는다.
5. 소개·운영목적처럼 한 문장인 본문을 문단으로 나누려고 새 문장을 작성하지 않는다.
