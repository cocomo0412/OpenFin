# 자료 묶음 버전 마지막 자리 표기 통일

- 작업일: 2026-10-07 (한국시간)
- 요청: `2026.10.07.1`의 마지막 자리를 `2026.10.07.01`로 맞춘다.
- 구현: PM·서버 개발 담당. 독립 검증: 별도 품질검증 담당.

## 변경

- 현재 공개 산출물의 버전을 `KR-FINANCE-ONTOLOGY-MANIFEST-2026.10.07.01`로 변경하고 manifest 체크섬을 재계산했다.
- `scripts/knowledge/manifest-version.mjs`의 생성 규칙을 `YYYY.MM.DD.01`로 변경했다. 같은 수집 기준일의 접미사는 `01`을 유지하는 기존 정책을 따른다.
- 수집 근거가 없는 과거 버전의 보존 동작은 유지한다. 과거 검증·배포 증적은 소급 변경하지 않는다.
- 원자료, 수집일, 빌드 시각은 변경하지 않았다. 현재 manifest는 버전과 체크섬 외에 변경이 없다.
- 양 매뉴얼과 변경 이력을 1.6.2로 갱신했다.

## 검증

- `node --test tests/knowledge/manifest-version.test.mjs`: 6건 통과.
- `git -c core.whitespace=cr-at-eol diff --check`: 통과.
- 별도 품질검증 담당 최종 판정: 통과. 6개 테스트·체크섬·HEAD 대비 두 필드 외 동일성·MCP 번들 입력 무변경을 독립 확인했다.
- 기존 상태 참고: `current-release.json`의 manifest 체크섬은 변경 전 HEAD의 manifest와도 이미 달랐다. 이번 표기 변경에서 생긴 회귀가 아니므로 과거 배포 포인터를 임의로 갱신하지 않았다. 배포 시 별도 정합성 확인 대상으로 남긴다.

## 반영 범위

- 로컬 수정 완료. 원격 반영·운영 배포는 하지 않았다.
- 홈페이지 배포 필요: 공개 manifest를 읽는 화면의 버전 표기 반영.
- MCP 재배포 불필요: MCP 코드·설정·의존성 및 무료 MCP의 세금 카탈로그 번들 입력 변경 없음.
- 자료 수집·자동 예약 실행 없음.
