# 사용자 관점의 OpenFin MCP 신뢰 검토

검토일: 2026-10-07 (한국시간). 담당: 사용자 경험 담당 AI, PM 사실 대조.
범위: 홈페이지·연결 안내·공개 문서·무료 MCP 제공 계약. 사용자 인터뷰나 전수 보안 감사는 아니다.
기준: 로컬 HEAD `b0a18e28805750539272dd19e372fb7aeab49fe5` 및 현재 공개 홈페이지·공개 `/health` 응답. 별도의 MCP 연결·도구 호출이나 방문 통계 분석은 하지 않았다.

최초 검토는 제안만 작성했다. 이후 사용자 요청으로 TRUST-01~03을 로컬 수정·검증했으며, 상세 결과는 [높음 3건 조치 기록](mcp-trust-high-fixes.md)에 남겼다. TRUST-04~07은 제안 상태이며 운영 반영은 별도다.

## 확인한 현재 제공 범위

- 운영 `/health`: `edition=free-tax-pilot`, `domain=tax`, `item_count=399`, `basis_date=2026-05-04`.
- `comparison_enabled=false`, `recommendation_enabled=false`, 인증 없음.
- 무료 구현은 `mcp/src/free-catalog.ts:1`의 정적 카탈로그를 가져온다. 홈페이지 전체 API 수집 현황과 같은 실시간 자료 공급 경로가 아니다.
- 카탈로그 기준일은 개별 제도의 적용일과 다르다. 5월이라는 날짜만으로 모든 항목이 틀렸거나 만료됐다고 판정하지 않는다.

## 우선 실행안과 배포 구분

먼저 TRUST-01~03의 제공 범위·날짜·문서 불일치를 해소한다. 이어 TRUST-05의 연결 성공 예시, TRUST-06~07의 문의·정책 접근 경로를 보완한다. 이용 제한을 숨기거나 검사 없이 “검증 완료”라고 붙이는 방식은 제안하지 않는다.

- 위 안내·문서만 고치면 홈페이지 또는 저장소 문서 반영만 필요하다.
- MCP의 실제 응답·번들·연결 처리까지 변경할 때만 MCP 배포가 필요하다.
- 최초 검토에서는 구현·운영 반영하지 않았다. 후속 TRUST-01~03은 로컬 수정·검증 완료, 원격 미반영이다. 앞선 UI 정리 배포 및 미배포 카드 간격 수정과 구분한다.
