# Cloudflare 무료 한도와 축소판 생성 기록 확인

확인일: 2026-10-07 한국시간. 사용자 요청으로 전체판 연결 작업을 보류하고 읽기 전용 확인을 수행했다. Cloudflare 요금제·설정 변경, Worker 업로드, 전체판 실행 부하 시험은 수행하지 않았다.

## 현재 계정 직접 확인

사용자가 로그인한 Cloudflare 대시보드에서 확인했다.

- Workers 요금제: 무료 US$0, ‘현재 요금제’ 표시.
- 계정 요금제 화면: 일일 100,000 요청, 요청당 최대 CPU 10ms, 하위 요청 50회.
- openfin 프로덕션 설정: 호환성 날짜 2026-09-16, nodejs_compat, 바인딩 없음. CPU 한도를 따로 올린 설정은 화면에서 확인되지 않았다.
- 개요의 최근 24시간 요약: 67회 호출, CPU 시간 표시 827µs, 오류 0. 이 요약은 전체판 성능 검사나 최대 CPU 측정치가 아니며 현재 축소판의 관찰값이다.

## 공식 문서 대조

[Cloudflare Workers Limits](https://developers.cloudflare.com/workers/platform/limits/) 확인: HTTP 요청 CPU Free 10ms, 메모리 128MB, Worker 비압축 번들 64MiB, 시작 시간 1초. 네트워크 대기시간은 CPU 시간과 구분된다. 번들 크기와 런타임에서 불러오는 자료 크기·메모리는 별개의 지표다.

## 실제 로컬 크기 확인 — 배포 없음

설치된 Wrangler 4.147.0의 `deploy --dry-run`만 실행했다.

| 대상 | 비압축 Total Upload | gzip 참고값 |
| --- | ---: | ---: |
| 현재 무료판 src/free.ts | 2195.21KiB (약2.14MiB) | 371.35KiB |
| 전체판 src/index.ts | 2304.11KiB (약2.25MiB) | 415.48KiB |

전체판 크기 측정은 무바인딩·동일 호환성 날짜/플래그의 로컬 임시 설정을 사용한 코드 번들 측정이다. 전체 자료는 외부 로딩 구조이므로 이 값에 모든 원자료가 포함된 것은 아니다. dry-run 성공은 Cloudflare 업로드 승인·시작시간·요청 CPU·메모리 통과를 입증하지 않는다.

두 번들 모두 확인한 공식 크기 한도 안에 있다. 따라서 현재 확보한 증거로는 **프로그램 파일 크기 때문에 세금 자료만 가능하다**고 결론낼 수 없다. 전체판의 CPU·메모리 안정 운영은 여전히 미검증이며, 앞서 확인한 자체 4MiB 파일 로드 제한과 약14MB 검색 자료 간 충돌도 남아 있다.

## 무료 축소판 기록의 정확한 위치와 날짜

- 커밋: [a8c98d47c34c6f070c03fe8822f57766cbd8e072](https://github.com/cocomo0412/OpenFin/commit/a8c98d47c34c6f070c03fe8822f57766cbd8e072)
- 작성 시각: 2026-09-16 19:31:25 +09:00.
- 제목: `Prepare a bounded public tax MCP for Cloudflare Free`.
- 당시 추가 문서 `mcp/FREE-DEPLOYMENT.md`: 세금·공제 387개, 전체 금융 분야 검색 미제공, 무료 CPU 제한 적용 명시.
- 당시 추가 생성기 `mcp/scripts/build-free-catalog.mjs`: 세금 파일 하나, 500건·600,000바이트 자체 제한.

이는 무료 운영을 염두에 둔 축소 구현의 기록이다. 사용자 승인 대화의 증거가 아니며, Cloudflare가 500건·600KB 또는 세금만 제공하도록 강제했다는 증거도 아니다. 과거 upstream CPU 실패 기록을 현재 계정의 전체판 성능 결과로 소급 적용하지 않는다.

결론: 사용자 지시에 따라 전체판 연결·배포는 보류한다. 무료 전체자료 제공의 가능/불가능을 확정하려면 자체 자료 로딩 제한을 해결한 후보에서 실제 CPU·메모리 및 첫 요청 성능을 검증해야 한다. 이 확인만으로 유료 전환이 필수라고 판단하지 않는다.
