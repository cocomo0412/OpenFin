# 좁은 화면 요약 카드 간격 축소

2026-10-07 사용자 추가 요청. 로컬 수정 완료, 운영 미배포.

- 원인: 2열·1열 전환 후에도 데스크톱용 카드 최소 높이 132px가 남아 큰 행간이 발생했다.
- 조치: 1060px 이하에서 최소 높이를 해제하고 상하 여백을 24px에서 16px, 숫자와 제목 간격을 6px에서 4px로 조정했다.
- 숫자 31px·상단 정렬·기존 열 전환 규칙은 유지했다. 1060px 초과 화면은 변경하지 않았다.
- 실제 CSS 너비 850px에서 일반 카드 높이 약 83px, 기준일 카드 118px 확인. 너비 390px의 1열에서도 일반 카드 83~84px, 넘침 없음 확인. 기준일 카드에는 추가 설명이 있으므로 내용에 맞춰 높이가 늘어난다.
- 독립 품질검증 담당의 미디어쿼리·캐시버전·영향 범위 정적 검토 통과. 변경 형식 검사 통과.
- [로컬 화면 증적](compact-metrics.png).
- 홈페이지 배포 필요: CSS 및 캐시 버전 변경. MCP 배포 불필요: 코드·설정·번들 입력 무변경. 이번 요청에서 배포는 실행하지 않았다.
