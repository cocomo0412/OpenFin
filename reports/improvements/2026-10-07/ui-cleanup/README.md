# 공개 상태 안내 정리와 요약 수치 크기 통일

작업일: 2026-10-07 (한국시간). 로컬 수정 완료, 원격 반영·배포 미실행.

## 사용자 요청과 변경

- 공식 API의 특정 시점 수집 자료를 기준일·출처와 함께 안내하는 기조를 적용했다.
- 검색 결과의 상태·최신성 배지와 공식 목록 수록·신청·가입 가능 여부 미확인 문구를 제거했다.
- 상세 최신성 문구, 상태 관련 5개 정보 필드, 출처 카드의 최신성 문구를 제거했다. 기준일·검토일·출처 링크와 원자료·내부 점검 상태는 보존했다.
- 개인사업자 대출상품 상세에서 지적된 문구 제거를 실제 브라우저에서 확인했다. 아직 수집된 상품 행이 없는 분류라는 설명은 사실 정보로 유지한다.
- 홈페이지 요약 수치 5개의 글꼴 크기를 31px, 굵기 400으로 통일했다. 기존 앞 2개와 뒤 3개의 서로 다른 크기 규칙을 제거했다.
- 추가 요청에 따라 카드의 세로 중앙 정렬을 상단 정렬로 바꿨다. 설명이 있는 기준일 카드도 숫자 시작 위치 24px, 제목 시작 위치 61px로 다른 카드와 일치한다.
- 안내 기조를 양 매뉴얼 1.6.3과 변경 이력에 반영했다. 기존 비API 자료의 출처·날짜는 보존한다.

## 검증

- JavaScript 문법 검사 통과.
- 검색 입력·검색 계약·출처 표시 관련 31건 통과.
- 배포 전 검색 품질 workflow와 버전 검사 묶음 65건 통과.
- 독립 품질 담당이 상세 상태 5개 필드까지 제거, 날짜·출처 유지, 글꼴 공통 규칙 및 매뉴얼 1.6.3을 재검토해 통과 판정했다.
- 브라우저에서 모든 요약 수치의 computed font-size 31px, font-weight 400 및 셀 넘침 없음을 확인했다. 뷰포트 변경 요청 시에도 같은 결과였다. 다만 도구의 요청 너비와 실제 CSS 너비에 차이가 있어 특정 모바일 기종과 동일한 환경이라고 단정하지 않는다. 증적 캡처 당시 실제 CSS 너비는 1071px였다.

## 배포 구분

- 홈페이지 배포 필요: HTML·공통 JavaScript·CSS 변경. 앞서 준비한 manifest `.01` 변경도 미배포 상태다.
- MCP 재배포 불필요: MCP 코드·설정·의존성·세금 카탈로그 번들 입력 무변경.
- API 재수집 및 자동 예약 변경 없음.
