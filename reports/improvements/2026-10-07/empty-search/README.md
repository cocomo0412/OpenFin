# OF-20261007-01 검색어가 남아 있을 때 0건 안내 개선

발견일: 2026-10-07 한국시간. 우선순위 P2. 사용자 제보와 공개 화면·코드 확인에 따른 개선이다.

## 문제 및 조치

분야를 바꿔도 기존 검색어는 유지된다. 사용자는 모바일에서 세제혜택 계좌를 선택한 뒤 0건을 보고 자료가 없다고 오해했다. 사용자가 이전 검색어가 있었다고 확인했고, 검색어 없는 공개 화면에서는 자료 10개(계좌 상품 4개 포함)가 표시됨을 확인했다.

검색어가 있는 0건에는 ‘현재 검색어로 찾은 결과가 없습니다.’와 ‘검색어 지우기’ 버튼을 추가했다. 버튼은 검색어만 비우며 분야·자료 유형을 유지한다. URL에서 q만 제거하고 검색창으로 포커스를 돌린다. 검색어 없는 0건에는 불필요한 지우기 버튼을 표시하지 않는다.

## 독립 검증

화면 구현 담당과 다른 주 담당자가 코드·회귀검사·실제 브라우저를 검증했다.

- 검색 입력·검색 계약·공식 API 자료 화면 검사 41/41 통과. JavaScript 구문 검사 통과.
- 모바일 화면 390×844에서 세제혜택 계좌 + 계좌 상품 + 신용대출 검색어로 0건 안내·버튼 확인.
- 버튼 클릭 후 같은 분야·유형의 계좌 상품 4개 복원, 검색어 삭제, q 제거, 검색창 포커스 확인.
- 0건 발생 시 이전 상세 선택이 해제되고 삭제 후 임의로 복원되지 않음.
- 모바일 터치 버튼 최소 높이 44px. 새 외부 요청·인증정보 취급 없음.
- `mobile-empty.png`: 로컬 수정 화면의 0건 안내 증적. 운영 화면 검증은 배포 후 별도 기록.

## 배포

홈페이지 변경 대상이며 예·적금 재수집 자료와 함께 배포한다. MCP 코드·설정·의존성·세금 번들 입력은 변경 대상이 아니다. 최종 원격 차이 및 실제 배포 결과는 [자료 반영 회차](../../../refresh-runs/2026-10-07/bank-followup/README.md)에서 관리한다.
