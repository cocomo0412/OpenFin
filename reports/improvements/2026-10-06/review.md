## OF-20261006-01 출처 안내 상충

- 재현: [영농조합법인 등에 대한 감면](https://cocomo0412.github.io/OpenFin/explorer.html?domain=tax#corporate.support.agricultural-corporation-reduction) 상세를 연다.
- 관찰: 상단은 **출처 점검 완료**, 같은 화면 출처 카드는 **최신 여부 재확인 필요**를 표시한다. 자료 검토일은 2026-09-24이며 출처 확인 기록은 2026-09-13T14:49:48.328Z다. 이 날짜를 오늘 확인한 법령 검증일로 해석하면 안 된다.
- 원인 근거: `docs/app.js:617`의 항목 상태 계산은 `source_ids`를 읽지만 원본의 `sources` 관계를 반영하지 않아 항목에 남은 `current`를 사용할 수 있다. 출처 카드 계산과 결과가 갈린다.
- 영향: 이용자가 본문의 출처 확인 상태를 실제보다 낙관적으로 이해할 수 있다. 감면 내용 자체가 틀렸다고 확인한 것은 아니다.
- 조치: compact/원본의 출처 식별자 계약을 통일하고 항목·출처 카드에 같은 보수적 상태 계산을 적용한다. 원자료 날짜를 바꾸지 않는다.
- 완료 조건: 동일 항목에서 상단과 출처 카드가 같은 경고 수준이며 전체 검색과 상세 로딩 전후에도 유지된다.
- 증적: [화면](evidence/05-conflicting-freshness.jpg), [화면 텍스트](evidence/05-conflicting-freshness.json), [저장 자료 대조](evidence/data-contract-observations.json).

- 재현: [정부24 지자체 지원금 수집 자료 링크](https://cocomo0412.github.io/OpenFin/api-data.html?source=source.gov24.benefit-plus.local-supports&operation=serviceList)를 연다. 해당 조합은 `docs/app.js:835`의 관련 자료 링크에도 정의되어 있다.
- 관찰: URL은 정부24를 지정하지만 선택 메뉴와 첫 카드가 **한국은행 기준금리 · StatisticSearch**로 표시된다. 수집일 2026-10-01, 46행이 나타나며 대상이 없다는 안내는 없다.

- 완료 조건: 정상 링크·존재하지 않는 조합·미공개 조합 모두에서 엉뚱한 첫 자료로 대체하지 않는다.
- 증적: [화면](evidence/04-source-link-wrong-dataset.jpg), [주소/선택값](evidence/04-source-link-wrong-dataset.json), [QA 재현](evidence/qa-reproduce-output.txt).

- 조치: 상세 자료 캐시 적재와 현재 탐색 분야 변경을 분리하고 최신 선택 토큰을 확인한다.

## OF-20261006-06 공식 API 자료 화면 개선 제안

- 재현: [공식 API 수집 자료](https://cocomo0412.github.io/OpenFin/api-data.html)를 기본 상태로 연다.
- 관찰: 첫 카드들이 모두 한국은행 기준금리라는 제목과 원자료 필드 보기만 보여준다. 날짜와 통계값은 펼쳐야 알 수 있다. `StatisticSearch`, 선택 자료 JSON, 온톨로지 탐색기 표현이 일반 검색 화면과 섞여 있다.
- 영향: 동일 제목 카드 사이의 차이를 빠르게 비교하기 어렵다. 원자료 전용 화면이라는 성격을 고려해 일반 요약과 기술 원문을 구분하는 제안이다.
- 조치: 날짜·값·단위를 카드 요약에 우선 표시하고 메뉴명·아이콘을 통일한다. 기술 필드를 기본 정보 대신 내세우지 않는다.
- 완료 조건: 원문을 펼치지 않고도 카드의 기준일과 핵심 값을 구별할 수 있다.
- 증적: [화면](evidence/03-api-summary-hidden.jpg), [기본 카드 텍스트](evidence/03-api-summary-hidden.json). 근거 `docs/api-data.js:8–23`, `docs/api-data.html:4–7`.

## 이번 작업의 반영 범위

이번 회차는 **탐색·증적·관리 절차의 로컬 기록**이다. 서비스 코드·금융 원자료를 수정하지 않았고 홈페이지·MCP 재배포는 필요하지 않다. 기록의 원격 push는 수행하지 않았다. 데이터/개발/QA의 분석을 총괄이 통합했으며 가설과 확정 관찰을 구분했다. 자동 반복 점검은 새로 설정하지 않았다.

검토 완료: 독립 QA가 보고서·매뉴얼·저장 증적의 주장 범위와 상대 링크를 검토해 승인했다. 총괄은 증적 14개 파일의 SHA-256 대조와 링크 누락 0건을 확인했다.
