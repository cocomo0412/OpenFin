- 코드 212개는 웹·CI 30개, MCP 91개, 수집·빌드·검사 87개, 외부 vendor 3개, 이전 검증 증적 스크립트 1개다. MCP의 생성 타입 선언도 포함되므로 모두 직접 작성한 실행 코드라는 뜻은 아니다.
- 추가 설정·계약·스키마 56개를 별도 목록화했다. 일부는 위 코드와 겹친다. 패키지·lock·MCP 설정의 세부 평가는 담당 보고서를 따른다. 계약·스키마는 필수 필드, 허용 속성, 출처 URL 형식, 공개 추천 차단 상태를 정적으로 확인했다. 모든 금융 규칙의 의미와 법적 유효성을 검증한 것은 아니다.
- JSON 7,329개를 전부 파싱했고 문법 오류는 0개였다. 이 검사는 자료 누락·오래된 조건·관계의 의미상 정확성을 보장하지 않는다.
- 이전 증적 `reports/improvements/2026-10-06/evidence/qa-reproduce.mjs`는 메모리 가상 입력을 쓰는 읽기 전용 재현 스크립트다. 기관 요청·배포·자격증명 접근 경로가 없고 과거 결함 관찰용이다. 기존 증적을 보존하기 위해 재실행하거나 결과를 덮어쓰지 않았다.

## API 키 보호 확인

현재 추적 텍스트 8,132개에 대해 private key, GitHub token, AWS access ID, OpenAI 형태 token, 자격증명 URL query 패턴을 검사했다. 일치 문자열이나 비밀값은 보고서에 저장하지 않았다. `.env.example`을 제외한 비공개 환경 파일의 Git 추적은 0개다.

패턴 후보는 40건이었으며 모두 예금자보호 상품 식별자의 `sk-`로 시작하는 영문 상품명 부분이었다. 금융상품 ID 문맥과 소문자 slug 형태를 확인해 40건 전부 오탐으로 분류했다. 이 범위에서 확인된 실제 키 노출은 0건이다. 패턴에 맞지 않는 키, 무작위 문자열에 숨긴 키, Git 과거 이력, 무시된 로컬 파일, 원격 secret·로그는 검사하지 않았으므로 “키가 절대 노출되지 않는다”는 보장은 아니다.

실행 코드 [audit-structure.mjs](audit-structure.mjs)와 결과 [structure-scan.json](structure-scan.json)을 보존한다. 스크립트를 다시 실행하면 기존 결과를 갱신하므로 후속 회차에서는 날짜별 새 경로에 실행한다. 후보의 오탐 판단은 결과의 `secret_triage`에 별도로 기록했다.

## 개발보안팀 반영

기존 5개 역할에 보안 설계·구현 검토와 독립 보안 검증을 추가해 총 7개 역할을 문서화했다. 이번 검토는 담당별 분석 후 총괄이 핵심 소스 근거·운영 도달 조건·범위 목록을 대조했다. 실제 수정이 없으므로 수정 완료나 수정 후 독립 보안 검증 완료로 표시하지 않는다.

팀 지침과 개발·운영 매뉴얼은 공통 버전 1.3.0으로 갱신했다. 역할 배정은 이 채팅의 AI 검토 체계이며 상시 실행 조직 또는 외부 보안 인증이 아니다.
