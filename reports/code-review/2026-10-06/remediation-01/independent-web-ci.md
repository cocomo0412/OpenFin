# 웹과 CI 조치 독립 검토

검토일: 2026년 10월 6일 한국시간. 총괄이 품질 담당의 SEC-05·07·08 구현을 별도로 검토했다. 대상은 legacy renderer, 출처 표시 검사, staging·release·search-quality workflow 및 새 회귀 검사다.

판정은 로컬 수정 승인이다. 악성 URL을 받은 모든 기존 출처 링크 출력 지점이 공통 HTTP(S) 검사와 HTML escape를 거치며, 잘못된 주소는 실행 가능한 링크로 만들어지지 않는다. 현재 내장 금융자료를 수정하지 않았고 생성 템플릿이 현행 저장소에 없다는 점을 확인했다. 현행 renderer를 관리 원본으로 검사한다.

staging의 사용자 입력과 release의 동적 작업 결과는 shell 코드에 직접 삽입하지 않고 환경 변수로 전달한다. staging에는 네트워크 검사 전 commit·checksum·version 형식 검사가 추가됐다. 기존 일치 검사와 17개 job의 비활성 조건을 유지한다. 수정된 보안 검사와 출처 표시 검사를 활성 search-quality 실행 목록·변경 경로에 연결한 것을 확인했다.

총괄이 실제 활성 workflow와 동일한 검사 목록을 재실행하여 57개 통과, 실패·skip 0개를 확인했다. [실행 로그](web-ci-tests.log)를 보존했다. URL 검사는 각 출력 지점에 javascript/data/vbscript, 혼합 대소문자, 제어문자, 사용자정보 포함 URL, HTML 특수문자를 넣어 거부·escape를 확인하며 정상 HTTP(S)는 보존한다. CI 검사는 실제 입력 검증문과 비교문을 사용해 잘못된 형식과 명령 치환 입력이 코드로 실행되지 않는지 확인한다.

SEC-07의 이전 영문 문구 기대값 두 건은 현재 한국어 표시와 일치하도록 고치되, 공식 제공기관 우선·오래된 자료 경고·확인일·기록 없음 구분을 검증하는 의미를 유지했다. 서비스 표시를 과거 검사에 맞춰 되돌리지 않았다.

실제 운영 workflow나 브라우저 공격을 실행한 결과는 아니다. 홈페이지 반영은 필요하고 현재 미배포다. 전체 조치 묶음의 MCP 의존성 변경은 별도로 배포 판단한다.
