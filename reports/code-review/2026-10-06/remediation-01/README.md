# OpenFin 코드 검토 12건 조치 결과

2026년 10월 6일 한국시간. 사용자 요청한 **SEC-01부터 SEC-12까지 12건의 로컬 코드 수정과 관련 검증을 완료**했다. 구현자와 다른 담당의 독립 검토에서 발견한 회귀도 보완했다. 홈페이지와 MCP의 원격 반영·운영 배포는 아직 하지 않았다.

[최초 검토 보고서](../review.md)와 당시 증적은 보존하고 이 후속 경로에 조치 결과를 추가했다. 최초 보고서의 미조치 상태는 최초 검토 시점의 기록이다. 현재 상태는 아래 표와 [조치 상태 JSON](actions.json)을 따른다. 매뉴얼은 **1.4.0**으로 갱신했다.

각 목록에 겹치는 검사가 있어 위 숫자를 합산한 고유 검사 건수로 주장하지 않는다. 실제 기관 API 호출이나 현행 금융자료 전체 재빌드는 하지 않았다. 기존 전체 지식 검사 중 현재 저장소 자료를 다시 쓰는 검사는 제외하고, 변경된 실패 경계는 메모리 응답과 별도 임시 자료로 검증했다.

배포 번들을 만들 때 Windows 작업 파일 줄바꿈 차이 때문에 무료 카탈로그의 원자료 해시만 일시적으로 달라졌다. 항목·날짜는 동일함을 확인하고 로컬 SDK 검사 후 기존 카탈로그로 복원했다. 원자료 수집일 갱신이나 금융자료 내용 변경은 없다.

## 독립 검토와 보완

- [MCP·의존성 독립 검토](independent-mcp.md): 단일 객체 부채 입력이 미입력으로 바뀌는 회귀를 발견해 보완했다. 이후 집중 검사와 타입 검사를 통과했다.
- [파이프라인 독립 검토](independent-pipeline.md): 살아있는 하위 작업의 늦은 쓰기, 동시 복구 잠금 경쟁, 실행 직전 PID 미등록 경계를 발견해 보완했다. 안전하게 종료 여부를 확인할 수 없으면 복구를 차단하고 백업을 보존한다.
- [웹·CI 독립 검토](independent-web-ci.md): 출처 출력 지점, 실행문 입력 경계, 기존 화면 계약, CI 검사 연결을 확인하고 동일 검사 목록을 별도로 실행했다.

## 운영 적용과 남는 경계

**홈페이지 배포가 필요하다.** 레거시 출처 링크 보호가 공개 화면 변경이다. **MCP 배포도 필요하다.** 무료 번들에 포함되는 의존성이 바뀌었다. 수집기 변경 자체로 원자료를 다시 수집하거나 두 서비스를 자동 재배포하지 않았다. CI 수정은 원격 저장소에 반영되어야 적용된다.

SEC-04는 정규 로컬 생성 작업의 검증·복구를 제공한다. 여러 디렉터리를 동시에 공개 전환하는 배포 방식이 아니므로 활성 journal이 있는 작업 자료는 배포하면 안 된다. 개별 inventory/integrate를 직접 실행할 때에는 전체 복구 단위가 적용되지 않는다. 복구 준비·실행 예약 중 강제 종료되어 상태가 불명확하면 자동 복구를 멈추며 [운영자 점검 절차](pipeline.md)를 따른다.

SEC-11은 실제 backend 코드까지 구현했지만 현재 무료 운영에 공유 저장소 binding·migration을 추가하지 않았다. 전체판을 나중에 활성화할 때는 해당 연결과 Cloudflare 실제 환경 검증이 필요하다. 미연결 상태에서 인증을 허용하는 임시 대체 경로는 없다.

로컬 수정 완료를 운영 배포 완료로 표시하지 않는다. 이 보고서의 검증은 전체 서비스에 취약점이 없다는 인증이 아니다. 초기 검토의 별도 원격 권한·과거 이력 조사 등 5개 확인 과제는 이번 12건과 별개다.
