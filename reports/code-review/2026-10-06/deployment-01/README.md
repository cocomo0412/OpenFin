# OpenFin 보안 조치 운영 배포 기록

2026년 10월 6일 **18:55 한국시간**, 홈페이지와 무료 MCP의 운영 배포 및 배포 후 검증을 완료했다. 사용자의 두 서비스 배포 승인을 받아 `3e225a1bad283d7898681cec88a47bcbe1e6f4c1`을 원격 main에 반영했다.

| 대상 | 배포 이유 | 결과와 증적 |
| --- | --- | --- |
| 홈페이지 | SEC-05 레거시 출처 링크 출력 보호 | [Pages 배포 성공](https://github.com/cocomo0412/OpenFin/actions/runs/37446057421). 공개 index.html·opentax/app.js의 응답 200 및 배포 커밋 원본과 SHA-256 일치 |
| 무료 MCP | SEC-01 운영 번들 의존성 보완 | [MCP 검증·배포 성공](https://github.com/cocomo0412/OpenFin/actions/runs/37446058959). 기존 Worker 업로드와 운영 공식 SDK 검사 모두 성공 |
| 검색·웹 보안 CI | 변경된 회귀 검사 및 안전한 출력 확인 | [검색 품질 검사 성공](https://github.com/cocomo0412/OpenFin/actions/runs/37446059092) |

운영 MCP를 별도로 재검증하여 초기 연결·서버 안내, search/fetch/exports 도구 목록, 월세 검색 3건, 상세 출처, 399개 항목 메타데이터, 원자료 체크섬, 없는 ID·길이 초과 입력·허용하지 않은 Origin·본문 크기 제한을 확인했다. 서버는 ready 상태다. 배포된 코드의 증거는 위 실행의 커밋과 업로드 성공이며, 기존 1.0.2 프로토콜 버전 문자열만으로 배포를 판정하지 않았다.

[배포 결과 JSON](deployment.json)에 각 실행의 작업·단계별 결과와 공개 파일 해시를 보존했다. [운영 SDK 결과](live-mcp-smoke.log)와 [재검증 코드](verify.mjs)를 함께 남겼다. Windows 작업 파일의 CRLF 차이를 피하기 위해 운영 자료 체크섬은 배포 커밋의 원본 Git 바이트로 비교했다. 운영 검증 과정에서 로컬 금융자료를 수정하지 않았다.

12건의 수정 코드는 원격 저장소에 반영됐다. 수집 파이프라인 수정은 다음 정규 API 수집·빌드부터 적용되며 이번에는 실제 기관 API 재수집을 실행하지 않았다. SEC-08~12 중 비활성 전체판·워크플로우는 그대로 비활성이다. SEC-11 전체판의 저장소 연결·migration 및 Cloudflare 실환경 검증은 해당 기능을 향후 활성화할 때 필요하다. 무료 MCP의 운영 범위는 검색·조회·자료 내보내기다.

최초 [검토](../review.md)와 [로컬 조치 증적](../remediation-01/README.md)은 당시 상태를 보존했다. 이 배포 기록이 최신 운영 상태를 나타낸다. API 키나 인증값은 기록하지 않았다. 금융자료 내용·수집일 변경은 없다. 이번 배포 뒤 추가한 증적은 로컬 기록 커밋으로 보존하며, 운영 배포 커밋과 구분한다.
