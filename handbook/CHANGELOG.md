# OpenFin 매뉴얼 버전과 변경 이력

현재 매뉴얼 버전은 **1.4.0**이다. 개발 매뉴얼과 운영 매뉴얼을 한 문서 세트로 관리하며 두 문서에 같은 버전을 표시한다. 버전은 `주버전.부버전.수정버전` 세 자리로 기록한다.

## 변경 기준

| 변경 종류 | 예시 | 기준 |
| --- | --- | --- |
| 작은 수정 | 1.0.1 → 1.0.2 | 오탈자, 설명 보완, 잘못된 명령이나 링크 수정 |
| 내용 추가 | 1.0.2 → 1.1.0 | 기존 절차를 유지하는 새 기능·운영 절차·검사 항목 추가 |
| 큰 변경 | 1.1.0 → 2.0.0 | 기존 절차로 운영할 수 없게 되는 구조·책임·배포 방식 변경 |

한 번의 검토된 변경 묶음에 버전을 한 번 올린다. 초안 수정이나 수정하지 않은 정기 점검마다 버전을 올리지 않는다. 상위 자리를 올리면 하위 자리는 0으로 시작한다.

## 기록 방법

- 변경할 때 두 매뉴얼의 버전과 이 문서의 현재 버전을 함께 갱신한다.
- 날짜, 변경 내용, 이유, 검토 결과, 반영 범위를 새 이력에 기록한다.
- 이전 본문은 Git 이력으로 보존하고 이전 변경 이력을 삭제하거나 새 내용으로 덮어쓰지 않는다.
- 자료만 갱신한 회차는 운영 회차 기록과 데이터 기준일로 관리한다. 매뉴얼 내용이 그대로라면 매뉴얼 버전을 올리지 않는다.
- 서비스 코드 버전과 매뉴얼 버전은 구분한다. 문서 버전 변경만으로 MCP 버전이나 데이터 날짜를 변경하지 않는다.
- 문서 버전은 운영 배포 완료의 증거가 아니다. 로컬 저장, 원격 반영, 운영 배포 여부는 별도로 기록한다.
